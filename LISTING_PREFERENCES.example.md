# Listing preferences

Copy this file to `LISTING_PREFERENCES.local.md` and fill in your own
criteria -- that file is gitignored, so it stays off the public repo.
It's just plain notes for you (and Claude, if you're using it) on what
you're actually looking for; nothing here is read by any script.

Example structure:

- **Primary target:** e.g. "3-bedroom places".
- **Also consider:** e.g. "2-bedroom + study as a substitute for the third
  bedroom".
- **Anything else that matters** but doesn't fit a database column --
  commute tolerances, must-have/nice-to-have amenities, dealbreakers, etc.
